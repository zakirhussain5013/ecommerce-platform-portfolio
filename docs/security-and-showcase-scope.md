# Security & Public Showcase Scope

This repository is a **documentation and visual portfolio only**. The application source and original engineering repositories remain private.

## Never Publish Here

- Backend, storefront, or admin source code.
- Git submodule metadata, private repository URLs, or private commit references.
- `.env` files, application settings containing credentials, connection strings, JWT secrets, API keys, tokens, or certificates.
- Production or staging infrastructure configuration, deployment runbooks, hostnames, IP addresses, runner details, or cloud credentials.
- Internal Claude/AI instructions, agent prompts, internal command catalogs, PR reviews, issue exports, or private engineering notes.
- Database dumps, customer data, logs, or uploaded user content.

## Public Repository Contents

Allowed content is limited to:

- Public-facing project summary and architecture explanation.
- Technology stack and high-level feature descriptions.
- Sanitized screenshots captured from the local UI.
- Editable, high-level architecture diagrams created for this portfolio.

## Accuracy

Architecture and technology statements are based on the supplied project documentation and source manifests. Screenshots are identified as local captures. Features described in planning/module documents are not presented as independently verified production behavior unless there is direct evidence.

## Secret Hygiene

The private source archive included configuration material that may contain populated credentials. Those values are intentionally not reproduced here. Before any public release of the original application repositories or artifacts, rotate any credential that may have been exposed outside its intended private environment and review repository history, build artifacts, and screenshots for accidental disclosure.
